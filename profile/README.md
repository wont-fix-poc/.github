# wont-fix-poc

> *"Thank you for your report. After careful review, we have determined this does not meet our bar for a security vulnerability."*

We disagree. This organization publishes proof-of-concept code for vulnerabilities that were reported and declined — `wont fix`, `by design`, `not a bug`, or no response.

**Report → wait → publish.** All PoCs are released for educational and research purposes.

*"Security through obscurity is not security."*
