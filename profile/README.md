# wont-fix-poc

> *"Thank you for your report. After careful review, we have determined this does not meet our bar for a security vulnerability."*

We disagree.

This organization publishes proof-of-concept code for vulnerabilities that were **reported to vendors and rejected** — marked as `wont fix`, `by design`, `not a bug`, or simply ignored with no response.

We believe the security community deserves to know.

## Disclosure Policy

1. **Report first** — every vulnerability here was submitted to the vendor before publication.
2. **Wait** — we give vendors reasonable time to respond and patch.
3. **Publish** — if the vendor closes the report without fix or acknowledgement, we publish.

We are not responsible for misuse. All PoCs are released for **educational and research purposes**.
